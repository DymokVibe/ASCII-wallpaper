# ASCII Live Wallpaper 2

Без Compose, ~1 МБ после R8. 5 сцен: макароны, кубы, большой куб, ДНК, чёрная дыра (+ режим «по кругу»).

## Сборка
**Android Studio:** File → Open → папка проекта → Build → Build APK(s) (вариант `release`).
**Командой (JDK 17 + Gradle 8.7):** `gradle assembleRelease` → `app/build/outputs/apk/release/app-release.apk`
**GitHub:** залей проект в репозиторий → вкладка Actions → Build APK → скачай артефакт.

Release подписан debug-ключом — для личной установки это нормально.
